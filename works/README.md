# Лабораторные работы по CUDA для ML/DL — 2026

В этом курсе мы пройдём путь от простых CUDA-ядер до обучения своей модели. В каждом задании смотрите, что нужно реализовать, как запустить программу и что показать в отчёте.

## Задания

1. [Векторные операции и активации](lab1.md)
2. [Матричное умножение](lab2.md)
3. [Оператор Собеля](lab3.md)
4. [Перцептрон для sin(x)](lab4.md)
5. [AlexNet-style на CIFAR-100](lab5.md)

## Общие требования

Основное решение пишите на C++/CUDA. Python пригодится для подготовки данных, проверки и экспериментов. Проверяйте ошибки CUDA и освобождайте ресурсы. Контрольный запуск должен пройти на учебном кластере Громозека.

Сначала проверяем корректность. Свой CPU-эталон писать не нужно: возьмите библиотечную операцию и сравните результаты на одинаковых входах и при сопоставимой точности. Библиотека не заменяет ядро, которое нужно реализовать в задании.

Затем разбираемся со скоростью. Прогрейте программу, укажите число повторов и приведите медиану или среднее с разбросом. Отдельно замерьте ядро, передачи и весь запуск; для GPU учитывайте асинхронность, а для времени приложения используйте CPU-таймер. В Lab 3–5 профилирование обязательно: найдите узкое место и сравните результат до и после изменения. В Lab 1–2 профилировщик — по желанию. Если ускорения нет, объясните почему.

Папку работы, сборку и отчёт оформляйте по [правилам сдачи](../docs/SUBMISSION_CONTRACT.md). Когда всё проверили, [откройте PR](../docs/SUBMISSIONS.md).

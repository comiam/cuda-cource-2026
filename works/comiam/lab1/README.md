# Проверка CI

## Описание

Синтетический пример для статической проверки, не решение лабораторной.

## Окружение

Linux, CUDA и CMake 3.20 или новее.

## Компиляция

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/submission
```

## Проверка корректности

Статическая проверка; CUDA-вычисления не выполняются.

## Результаты

Результат проверки публикуется в тестовом PR.

## Выводы

Пример проверяет доставку статуса в PR.

## Воспроизводимость

### Данные

Входные данные не нужны.

### Полный запуск

```bash
cmake -S . -B build
cmake --build build
./build/submission
```

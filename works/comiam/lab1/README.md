# Проверка CI: ошибка выполнения

## Описание

Синтетический пример для проверки сообщения об ошибке выполнения, не решение лабораторной.

## Окружение

Linux, CUDA и CMake 3.20 или новее.

## Компиляция

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/submission
```

## Проверка корректности

Программа намеренно завершает работу с кодом `1`; CUDA-вычисления не выполняются. Ожидается ошибка выполнения в обоих вычислительных режимах. CLI-контракт заглушка не реализует.

## Результаты

Результат проверки публикуется в тестовом PR.

## Выводы

Пример проверяет, что в PR не перепутаны ошибка выполнения программы и сбой инфраструктуры.

## Воспроизводимость

### Данные

Входные данные не нужны.

### Полный запуск

```bash
cmake -S . -B build
cmake --build build
./build/submission
```

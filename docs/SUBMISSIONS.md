# Как сдать лабораторную

## От форка до PR

1. Откройте [репозиторий курса](https://github.com/comiam/cuda-cource-2026) и нажмите **Fork**. Клонируйте свой форк. В примерах замените `ВАШ-ЛОГИН` на логин GitHub; если имя форка отличается, возьмите адрес на его странице через **Code**.

   ```bash
   git clone https://github.com/ВАШ-ЛОГИН/cuda-cource-2026.git
   cd cuda-cource-2026
   git remote add upstream https://github.com/comiam/cuda-cource-2026.git
   git fetch upstream
   git switch -c lab1 upstream/master
   ```

2. Создайте папку `works/<ваш-логин>/lab1/` по [примеру структуры](FOLDER_STRUCTURE.md). Соберите программу по [контракту](SUBMISSION_CONTRACT.md). К каждой работе есть [отдельное задание](../works/README.md) с правилами запуска. Заполните [README по шаблону](STUDENT_TEMPLATE.md).
3. Проверьте список изменений и добавьте в коммит только папку своей работы:

   ```bash
   git status --short
   git add -- works/ВАШ-ЛОГИН/lab1/
   git diff --cached --stat
   git commit -m "Lab 1: векторные операции и ReLU"
   git push -u origin lab1
   ```

4. Откройте Pull Request: база — `comiam/cuda-cource-2026:master`, ветка с работой — `ВАШ-ЛОГИН/cuda-cource-2026:lab1`. В PR должна быть только одна лабораторная.
5. Если проверка не прошла, откройте **Details**, исправьте замечания, сделайте новый коммит и `git push` в ту же ветку. PR обновится сам — новый не нужен.

## Как вести следующие работы

- Начинайте каждую лабораторную в отдельной ветке от актуальной ветки курса: `git fetch upstream`, затем, например, `git switch -c lab2 upstream/master`. Не делайте Lab 2 продолжением ветки ещё не принятой Lab 1.
- Коммитьте исходники, `CMakeLists.txt`, README и небольшие примеры. Сборку, большие данные и веса оставляйте локально; в README укажите, как их получить или сгенерировать. См. [что хранить в Git](FOLDER_STRUCTURE.md#файлы-в-git).
- Перед отправкой сверьтесь с [правилами форматирования](SUBMISSION_CONTRACT.md#форматирование) и просмотрите список файлов в PR: там не должно быть изменений в чужих работах или в общих файлах курса.

## Заголовок PR

```text
Иванов И.И. M4101. Lab 1: Vector Operations and Activations
```

Формат: `Фамилия И.О. Группа. Lab N: Название`. Укажите фамилию (кириллица или латиница, допустимы дефис и апостроф), один или два инициала с точками и группу (заглавная буква и 4–6 цифр). Номер работы должен совпадать с папкой. [Возьмите точное название из таблицы](SUBMISSION_CONTRACT.md#заголовок-и-описание-pr).

## Описание PR

```markdown
## Что сделано

Кратко опишите решение.

## Проверка

Напишите, какие кейсы проверили и что получилось.

## Отчёт

[README](works/ВАШ-ЛОГИН/lab1/README.md)
```

Замените логин и номер работы в ссылке. Путь указывайте от корня репозитория. Команды и измерения оставьте в README.

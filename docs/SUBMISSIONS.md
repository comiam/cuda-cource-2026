# Инструкции по сдаче лабораторных работ

## Fork + Pull Request

Каждая лабораторная сдаётся отдельным PR из вашего форка в основную ветку курса.

1. Создайте форк и клонируйте его:

   ```bash
   git clone https://github.com/<ТВ-ЛОГИН>/cuda-cource-2025.git
   cd cuda-cource-2025
   ```

2. Создайте ветку для лабораторной и папку `works/<github-login>/lab<N>/`. Название папки должно совпадать с вашим логином GitHub; регистр букв значения не имеет. Обязательны `CMakeLists.txt`, `README.md`, `src/` с CUDA-исходником. Структура описана в [FOLDER_STRUCTURE.md](FOLDER_STRUCTURE.md).
3. Выполните работу и заполните отчёт по [STUDENT_TEMPLATE.md](STUDENT_TEMPLATE.md). Используйте цель CMake `submission` и [единый CLI](SUBMISSION_CONTRACT.md#cli-программы).
4. Запушьте изменения в свой форк и откройте PR: `base: comiam/cuda-cource-2025:master` ← `head: <ТВ-ЛОГИН>/cuda-cource-2025:master`.
5. Заполните заголовок и описание по образцу ниже.
6. GitHub Actions автоматически выполнит проверки. Результат появится в PR как `submission/static`, подробности — в журнале и отчёте запуска.
7. Исправьте замечания в файлах или описании PR. Новый push и редактирование описания запускают проверку повторно.

## Заголовок PR

```text
Иванов И.И. M4101. Lab 1: Vector Operations and Activations
```

Формат: `Фамилия И.О. Группа. Lab N: Название`. Допускаются фамилии кириллицей/латиницей, дефисы и апострофы, один или два инициала с точками. Группа — заглавная буква и 4–6 цифр. Номер совпадает с папкой, название возьмите из [таблицы названий](SUBMISSION_CONTRACT.md#заголовок-и-описание-pr).

## Описание PR

В описании PR заполните три раздела:

```markdown
## Что сделано

Кратко опишите свою реализацию.

## Проверка

Укажите выполненные проверки и результаты.

## Отчёт

[README](works/ВАШ-ЛОГИН/lab1/README.md)
```

В ссылке укажите свой логин и номер лабораторной. Путь считается от корня репозитория. Подробные команды и измерения приведите в README.

## Что проверяет CI

- Что PR содержит только одну вашу лабораторную.
- Обязательные папки, `CMakeLists.txt`, README и CUDA-исходники.
- Размеры файлов, симлинки, submodules и сборочные артефакты.
- Заголовок и разделы описания PR.
- Разделы и оформление основного README, ссылки и инструкцию воспроизведения.
- Форматирование C/C++/CUDA, Python и CMake по конфигам курса.

Общие документы и CI обновляют сопровождающие курса отдельными PR.
